# 玻璃界面重置 · 2026-10-05

资产库改为银灰浅色 / 石墨深色界面，默认跟随系统。侧栏、详情和浮层使用磨砂玻璃；资产卡片保持实色，避免滚动区域反复进行大面积背景模糊。

## 最终行为

- 顶栏集中搜索、筛选、扫描队列、日志、详情开关和设置；去掉重复导航和装饰口号。
- 详情默认收起，选择资产时展开；关闭详情保留当前选择。
- 分类、收藏、批量操作、目录、标签、资源卡、查看器与文件操作继续使用原有 Core 接口及确认流程。
- 字体使用系统 UI 字体与中文 / 日文回退；统一字号、字重、行高、数字对齐和 Lucide 图标。主按钮文字随主题调整对比度。
- 卡片默认最小尺寸为 200 px，沿用已有尺寸偏好；调整尺寸不再通过 `key` 重建整个虚拟网格。
- 悬停使用小幅位移，详情采用 180 ms 淡入，浮层采用短过渡。系统减少动态效果或手动关闭动效时停用动画和过渡。
- 设置支持跟随系统 / 浅色 / 深色、透明效果、界面动效。偏好保存在本机；关闭透明效果时，侧栏、浮层及遮罩停用背景模糊。
- 设置、空状态、查看器标题只保留操作说明和状态信息；去掉英文装饰副标题及宣传式文案。
