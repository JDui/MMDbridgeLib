# 功能续测与修复（2026-10-05）

本轮接续全局功能审计，补充实际 CLI 进程调用、操作恢复证据和 Windows/Linux 文件移动、重命名验证。涉及资产的文件写入和清理验证均使用唯一命名的临时测试目录，未访问或修改用户真实资产，未启动用户桌面程序。

## 已完成的修复

1. **失败任务的 CLI 退出码。** `thumbnail enqueue/batch`、`cards generate/sync-manifest` 原先可能输出失败结果却以 0 退出。现在保留原有 JSON 结构，对失败、取消、部分失败或等待结束仍未完成的执行结果返回非零退出码。`jobs list` 等查询仍可成功读取包含失败任务的列表。
2. **操作日志的恢复证据。** 中断恢复与人工核对原先覆盖整个 `result_json`，丢失已完成、需要检查、未开始的路径，以及根 ID 和索引错误说明。现在只合并状态说明与时间，保留原有证据；重复核对不会再次修改记录，进行中的操作不能提前释放占用。
3. **Windows 移动后的依赖路径误判。** 新增实际移动用例发现：索引中的普通／短路径与规范路径混用时，直接对已移动的旧路径做前缀匹配会误判依赖在资产包外，导致移动回滚。现在在文件动作前解析各索引路径及其实际文件的目标映射，再在事务中更新索引；预检失败时文件动作不执行。
4. **操作日志的状态与可读性。** `Started` 显示“进行中”，`RecoveryNeeded` 显示“需要检查”，核对后显示“已核对”。仅待恢复的记录提供人工核对按钮；明细字体提升至 12 px，说明与记录标题为 13 px，日志列表按可用视口展开，避免单条展开记录把核对按钮挤到折叠区域。
