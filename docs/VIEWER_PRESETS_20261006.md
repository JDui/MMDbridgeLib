# 3D 查看器预设与场景参照（2026-10-06）

角色与动作窗口增加五种 Matcap 选项：原材质、柔光灰、白瓷、银灰、暖铜。采用已有 Three.js 的 MeshMatcapMaterial，预设纹理由本地确定性算法生成，不依赖网络、不增加生产依赖。

预设只切换网格材质，沿用已加载的几何、蒙皮、相机、轨道控制、帧请求队列与播放状态。原材质保留模型颜色和贴图；Matcap 保留原材质与贴图的 alpha、cutout 和 alphaHash 参数，不用贴图 RGB 染色。贴图晚于 Matcap 加载时继续更新透明遮罩。权重类型、逐骨骼和异常检查保留原始色阶，返回材质模式时恢复所选 Matcap。

场景窗口独立提供原始光照、柔和日光、暖色室内、冷色夜景和高对比预设。切换背景、环境光、三盏方向光、色调映射与曝光，不重载网格、不改变源材质、不重置飞行镜头。恢复原始光照时还原既有灯光和无色调映射。两类预设分别保存至现有安全偏好存储；角色与动作共享 Matcap 偏好。

设置项由“动作预览模型”改为“预览角色”，继续复用原有 motion_preview_model 设置与 Core PMX / PMD 预览命令。场景开启时默认加载该角色，在模型变换原点 (0, 0, 0) 放置，比例为 (1, 1, 1)，不居中、不归一化、不自动把脚贴地。源网格本身的偏移会保留，用于判断资产原点和原始尺寸。

场景底栏可隐藏或重载参照角色；“查看原点”从固定参照位置面向原点，且同步飞行控制的朝向状态。预览角色未设置或解析失败只显示必要状态，场景仍可移动、切换预设和关闭。隐藏、重载、切换资产和关闭会移除角色对象、释放资源，并丢弃过期异步解析或贴图结果。

## 验证

前端功能测试覆盖 Matcap 的 alpha 保留、后加载贴图、几何与蒙皮对象复用、原材质恢复和重复释放，以及场景原始灯光还原。已有存储失败、时间轴快速跳转、关闭时过期请求、相机取景和 Tauri 命令注册检查继续运行。

compatibility_probe 额外生成独立的合成 PMX / PMD 人形、场景和 60 帧 VMD；通过 Core 的 model_preview_file、scene_preview 与 motion_preview_frame 输出真实二进制和骨骼矩阵。原来的七项兼容性样例仍保留。

viewer-review.mjs 在隔离的 headless Chromium 中显示当前前端，使用测试 Tauri 桥提供上述 Core 数据；检查每种预设的实际画布差异、相机与几何保持、暂停帧和骨骼矩阵保持、连续播放、权重模式恢复，以及场景参照 PMX / PMD 加载、原点比例、隐藏、重载、缺少设置、读取错误、晚到结果和重新打开不重复。

截图和状态证据由 Model compatibility and offscreen rendering CI 的 MBL-Model-Compatibility 产物提供。此路径属于 Linux 合成素材、软件 WebGL 验证；Windows 真实素材和实际显卡画面仍须单独确认。
