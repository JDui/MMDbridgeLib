# 半透明、启动差量与场景移动修正（2026-10-01）

## 实现

- 模型、场景和动作查看器复用 `viewerRendering.ts` 的透明策略。原先把整个 PMX 材质组混合绘制且关闭深度写入；组内前后面无法通过材质中心排序正确遮挡。现在真正半透明的材质使用现有 Three.js r160 的 `alphaHash`，保留深度写入；裁切材质继续使用 MSAA alpha-to-coverage。切换查看模式时同步恢复材质状态。此方式避免三角面排序，半透明区域可能有轻微颗粒感，参见 [Three.js Material 文档](https://threejs.org/docs/pages/Material.html)。仅修改交互查看器，不改变 Core 缩略图版本。
- 文件监视器启动时调用 Core 的 `reconcile_root_changes`，不再无条件给每个根目录排整库扫描。Core 持久化路径、文件大小和纳秒修改时间的快照，通过内存映射比较新旧元数据，只把新增、修改、删除交给已有差量队列；运行期间继续复用文件监视事件。
- 差量检查仍需枚举目录及相关文件元数据，时间随文件数量增长；它不读取源文件内容、不计算内容指纹、不解析未变模型、不逐项校验资源卡。无变化时不新增扫描任务，也不重写快照。保留“扫描”和完整校验的手动入口。
- 首次升级、扫描范围或解析版本改变、快照不可用、上次扫描失败、大批量变更（超过 1,024 个路径）会回退到已有整库发现。外部贴图变化、未知监视事件、部分目录删除等也沿用现有安全回退。目录不可读时不推进快照；先把变更持久化进队列，再保存快照，暂停任务继续保持暂停。非递归根目录只发现直接子层的主文件，同时检查嵌套依赖。
- 场景 WASD/QE 移动：Shift 4 倍，Ctrl 0.25 倍，同时按下时 Ctrl 优先；左右修饰键均支持，已按住修饰键再进入视口也能识别。松开按键或窗口失去焦点会停止相应输入。视口增加操作提示。

## 场景鼠标锁定补充

场景 3DV 按住左键或右键转向时使用原生 Pointer Lock 隐藏并锁定鼠标，通过相对位移持续转向，避免鼠标移出视口或碰到屏幕边缘。松开拖动按钮、失焦、外部解锁或关闭查看器会释放锁定；若按钮在异步锁定完成前已松开，迟到的锁定也会立即释放。正常松开鼠标不清除仍按住的 WASD/QE 输入。模型轨道控制保持原有行为，非鼠标指针继续使用现有 Pointer Capture。复用 [Pointer Lock API](https://developer.mozilla.org/en-US/docs/Web/API/Pointer_Lock_API)，没有新增依赖。

当前 `ModelViewer.tsx` 的隔离无窗口 Edge 定向检查通过：左右键锁定、锁定期间越过视口边界仍可转向、松开释放并停止转向、失焦释放、外部解锁停止拖动；无页面错误。证据为 `target/transparency-20261001/pointer-lock-evidence.json`。真实 Tauri/WebView2 桌面操作尚未实机验证。
