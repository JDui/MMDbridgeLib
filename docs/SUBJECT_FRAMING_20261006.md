# 角色缩略图主体取景（2026-10-06）

用户要求尽可能让角色缩略图围绕主体显示。渲染器更新为 **0.6.1**，自动角色取景版本为 `front-minus-z-down5-subject-surface-msaa-v10`。既有卡片按版本检查进入待更新状态，继续使用已有缩略图重建队列。

## 行为

| 输入情况 | 自动角色缩略图 |
| --- | --- |
| 骨架范围巨大但网格正常 | 骨骼坐标不参与取景，使用实际网格主体 |
| 整个角色比例极小或极大 | 按相对尺寸取景，移除旧的固定 0.001 半径下限；包围盒、中心与自动投影使用双精度 |
| 未被面片引用的远处顶点 | 不参与取景 |
| 分离的远处面片或配件 | 优先主体与相邻网格，远处组件仅在该自动缩略图中省略 |
| 单个被引用顶点飞远 | 拆开异常拉长的面片，省略这些缩略图面片，避免它们撑大取景或遮挡主体 |
| 材质或三角形所有顶点 alpha 接近零 | 不作为主体取景依据，并省略对应缩略图面片 |
| 多个材质、UV 接缝、分离的头发 / 裙摆 / 翅膀 / 肢体 | 按相邻组件扩展主体集合，取全部保留顶点的边界，不直接按百分位裁掉末端 |
| NaN / Inf、越界索引或不完整材质覆盖 | 返回结构化渲染错误 |
| 没有可见、非退化或可信面片 | 带诊断回退至完整索引网格，不因主体选择为空而崩溃 |

仅改变自动缩略图的构图与临时绘制索引；不修改源 PMX / PMD，不删顶点，不修改资产统计、查看器网格或动画数据。报告的顶点 / 三角形数量仍对应源网格，省略数量另记于 `SubjectFraming:*` 诊断。

同时修复卡片图片容器的尺寸约束：图片作为绝对定位图层填满已有槽位，再由 `object-fit: contain` 显示完整方形缩略图。旧网格的图片固有尺寸可能撑大子项，导致脚部留白在矩形卡片中被裁切；卡片比例和布局不必改变。

场景固定相机及有效 VMD 相机轨道继续使用完整网格与原有相机，不应用角色主体过滤。VPD / 不含有效相机的 VMD 先求姿态，再使用此取景流程。

## 有界选择规则

1. 验证索引和连续材质覆盖。材质 diffuse alpha × texture-factor alpha 不大于 0.001，或启用顶点色且三角形三个顶点 alpha 均不大于 0.001 时，将面片从可见集合排除。
2. 从可见面片引用的唯一顶点估计主体初始尺度。至少 12 个顶点时，各轴去除两端约 1%（最少一个值）仅用于估计种子；最终构图不使用该百分位边界。
3. 最多抽样约 8,192 个三角形的边长和面积。以种子跨度、边长中位数估计相对尺度，只拆开边长超过该尺度六倍的异常拉长面片；尺度上限也受中位边长约束，避免远处顶点无限撑大阈值。
4. 对可信面片按索引建立连通组件，以三角形面积支持选主体；单面贡献上限为抽样中位面积的 128 倍，避免一张大破面压倒角色。标准身体骨骼名称和现有权重提供最高九倍支持提示，骨骼位置不参与。没有标准骨名时仍能按网格处理。
5. 从主体扩展相邻分离组件，采用最多 16 轮批次更新，避免依赖哈希遍历顺序。邻近距离不大于种子跨度的 0.75 倍；扩展受固定六倍跨度包络约束，远处碎片链不能无限移动构图。
6. 保留完整选中面片，重新建立材质索引范围，按全部保留顶点加约 8% 留白。取景分析周期检查取消，继续处于既有 Rendering 阶段。

实现位于 `src/thumbnail_framing.rs`，复用现有模型、蒙皮和渲染器，不增加生产依赖。分析采用有界抽样、选择算法和并查集；内存随已经有上限的网格顶点 / 索引规模线性增长。

## 验证路径

`thumbnail_framing.rs` 的九组单元测试覆盖远处未使用顶点、分离与连通飞点、相邻长发 / 裙摆 / 翅膀 / UV 接缝、密集远处几何与身体权重、透明材质与材质组保留、比例跨度与极端有限坐标、错误输入 / 取消、骨架坐标独立性，以及空可见集 / 退化回退。

`subject_framing_probe` 创建十一份合成角色样例，经公开 Core Library API 扫描、实际离屏渲染、建卡和校验。比较基线固定为 `03ae41203c436032180881c4e8b34b67622a80e8`（0.6.0），同一份生成源文件分别交给旧版和新版渲染。

`subject-review.mjs` 解码二十二张真实 Core WebP，检查主体占画面比例、异常样例改善、长发 / 裙摆 / 翅膀留白，并逐字节比较未受损的正常主体；再用当前前端与测试 Tauri 桥展示八份样例。截图是 Linux CI 合成样例与软件 Vulkan，不是 Windows 实机或用户真实模型截图。

本记录的运行结果、构建和截图证据在完成 CI 后补录。

## 限制

这是几何与现有骨骼权重的启发式主体选择，不是人物语义识别。比角色更占优势且没有可用身体权重提示的远处大物体、多角色文件、极长的分离附件或复杂破面仍可能选错主体或省略附件。完全透明贴图的可见性尚未逐三角形采样；只检查材质与现有顶点 alpha。首轮相对尺度很低的模型也可能把超长但合法的稀疏面片视作异常。

更多真实模型、多角色与复杂附件的效果仍需只读素材验证；本轮不将合成验证表述为所有模型均能正确构图。
