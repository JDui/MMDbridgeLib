# Library 启动、缩略图与场景查看器更新

日期：2026-09-30。

## 行为变化

- 数据库初始化移至启动后台线程，窗口显示品牌准备页及错误信息；准备好后默认进入 Library。首屏列表返回后才恢复扫描、缩略图队列和目录监视。没有测量冷启动耗时，不宣称具体性能提升。
- 模型自动取景改为 5° 微俯视，在相机空间取骨架范围与网格范围中较小的取景尺度，避免远离主体的骨骼扩大画面。VMD 自带相机轨道继续使用该轨道。
- 渲染器版本为 0.5.1，模型/场景设置版本为 v7/v3。打开库时将旧版资源卡标为 `CardStale`；设置新增全库重生成入口，复用现有可取消、可重试任务队列。源文件缺失、解析失败或不支持的资产，以及未配置预览模型的动作，会跳过并报告数量。
- 单资产“重新生成此缩略图”强制失效该预览缓存；完成后只更新对应卡片和已打开的详情/预览，不重载整个网格。
- 新增标签快速筛选、多个标签全部/任一匹配，条件由 Core 执行并与目录、类型、收藏、搜索和智能集合组合。仍使用已有游标分页。
- PMX 模型记录 `skeleton_class`；根据 MMD 躯干、头、左右手臂和腿的名称及父链分类，允许额外的扭转/IK 骨骼。“非标准”显示徽标并可筛选；未重扫的旧资产显示“待分类”。PMX 解析修订提高到 2，后台扫描会补齐分类，不写入用户标签。
- 场景查看器从缩略图相机位置 `(0, 165/8, 0)` 开始，朝 -Z、俯视 5°，视场角 90°。WASD 沿相机方向移动，Q 降/E 升，左/右键拖动控制朝向，重置返回起点。
- 工具栏允许换行以避免拥挤；无选择时隐藏无作用的详情取消按钮；目录面板改为手动展开/收起及高度过渡，避免滚动与面板高度互相触发。
- 贴图解码复用图像库的内容格式识别，TGA 保留去除扩展名尾部空格的回退；既有尺寸与内存限制继续生效。

## 启动页等待反馈修正

针对用户反馈的启动页长时间固定显示“正在打开本地资产库”，新增 Core 初始化进度回调，覆盖打开数据库、准备 WAL/读写、容量检查、结构升级、读取缩略图设置、检查/标记旧版预览六个阶段。启动页显示具体操作、阶段序号、总耗时、本阶段耗时；有实际数量的步骤显示完成数/总数及百分比。15 秒没有新进度时显示等待磁盘或数据库锁的提示，不把阶段序号伪装为耗时百分比。阶段记录写入程序旁的 `data/startup-progress.log`；启动线程异常也返回可见错误。

版本 15 的数据库不再重复准备基础表和初始化计数。旧版缩略图检查改为一次流式遍历，每 100 条报告检查数量；过期状态按每 100 条的小事务提交并报告标记数量，保留原有 `CardStale` 语义和有效新版预览。没有新增依赖、数据库版本或源素材写入。

验证：原库只读统计为 9,889 个资产，数据库约 177 MB；一轮只读统计用时约 31.5 秒，不能据此断言原启动卡住的精确位置。通过 SQLite 只读连接创建独立数据库副本，再执行 `copied_database_startup_progress`：六阶段均报告，检查 9,889 张卡片、标记 4,562 张过期预览，约 14.16 秒完成并成功读取 Library 首项。副本刚完成复制，可能有系统缓存；该结果不代表桌面冷启动速度。扩展后的定向版本/筛选回归测试通过，前端构建和 Rust 桌面离线检查通过。桌面启动页 IPC、布局及实机耗时仍未运行验证。
