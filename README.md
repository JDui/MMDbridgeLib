# MMDbridgeLib

> 🚧 **施工中**：项目仍在持续开发，功能和界面可能调整，尚未完成。

MMDbridgeLib 是一款面向 Windows 的本地优先 MMD 资产管理工具，旨在帮助用户集中整理和浏览模型、动作与场景等本地资源。

项目希望为大量 MMD 资产提供一个统一的资料库：自动扫描并建立索引，通过缩略图和模型预览快速浏览内容，再使用搜索、筛选、标签、收藏和智能集合查找所需资源。对于重复文件、动作关联和文件整理等工作，软件也会提供辅助信息与操作流程。

MMDbridgeLib 以 Rust 核心处理资产扫描、解析、索引和预览等工作，并由桌面界面及命令行工具共用，尽量让资产数据留在用户自己的设备上。

项目仍处于建设阶段，相关能力正在逐步实现和完善。
